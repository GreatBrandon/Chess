# Chess

Chess game and engine made by me

## Currently working:
- Simple chess UI using raylib
- Drag and drop pieces to play
- Simple game of chess with most legal moves checked on the go
- Working castling and en-passant
- Move history stored using notation and displayed
- Pre-generating all legal moves for rook, knight, bishop and queen

## WIP:
- Pre-generate all legal moves for pawn and king
- Remove checking legal moves on the fly and use the pre-generated list instead
- Pre-generate castling and en-passant
- Check, checkmate and stalemate calculation
- Use pre-generated moves to create basic engine randomly selecting a move from the list
- Basic engine recursively checking all paths
- Basic engine optimisations to increase speed
